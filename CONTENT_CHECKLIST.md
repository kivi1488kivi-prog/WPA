# ✅ Чеклист наполнения контентом

## 📸 Что нужно для полнофункционального барбершопа

### 1. Изображения (критически важно!)

#### Основные
- ✅ **Logo** (512x512px, PNG или SVG)
  - Фирменный логотип салона
  - Должен быть узнаваемым
  
- ✅ **Icon для приложения** (512x512px, PNG)
  - Квадратный
  - Без отступов вокруг (заполняет всю площадь)
  
- ✅ **Maskable Icon** (512x512px, PNG)
  - С отступом 10% от края
  - Для масок (iOS, Android)
  - Инструмент: https://maskable.app/
  
- ✅ **Cover фото** (1200x600px+)
  - Фасад салона ИЛИ интерьер ИЛИ команда
  - Качество: минимум 85% JPG качества
  - Привлекающее, профессиональное

#### Галерея (опционально)
- Фото интерьера (3-5 штук)
- Примеры работ (стрижки, бороды)
- Команда в действии
- Инструменты/оборудование

#### Профили барберов
- ✅ Фото каждого барбера (400x400px минимум)
  - Профессиональный портрет
  - Желательно в салоне
  - Хорошее освещение

---

### 2. Информация о салоне

#### Основное
- ✅ **Название** (`name`) - полное
- ✅ **Короткое имя** (`short_name`) - для логотипа
- ✅ **Слоган** (`tagline`) - 5-10 слов
- ✅ **Описание** (`description`) - параграф
- ✅ **Адрес** (улица, город, код, страна)
- ✅ **Контакты** (телефон, email)

#### Брендинг
- ✅ **Основной цвет** (`accent_color`) - HEX формат
- ✅ **Фоновый цвет** (`background_color`) - обычно тёмный
- ✅ **Язык** (`locale`) - de, en, ru
- ✅ **Часовой пояс** (`timezone`) - Europe/Berlin и т.д.
- ✅ **Валюта** (`currency`) - EUR, USD, RUB

---

### 3. Услуги и цены

#### Каждая услуга должна иметь
- ✅ **Уникальный ID** (`key`) - example: `haircut`, `beard-trim`
- ✅ **Название** (`name`) - например: "Herrenhaarschnitt"
- ✅ **Описание** (`description`) - что включено, чему занимает
- ✅ **Длительность** (`duration_min`) - в минутах
- ✅ **Цена** (`price`) - в выбранной валюте

#### Примеры хороших услуг:
```json
{
  "key": "haircut",
  "name": "Haircut with wash",
  "description": "Scissor cut, hair wash, styling. 30 minutes.",
  "duration_min": 30,
  "price": 25
}
```

#### Чего избегать:
```json
// ❌ ПЛОХО
{
  "name": "Service",            // не информативно
  "description": "Good service", // слишком общее
  "duration_min": 60,           // не ясно что это
  "price": 50                   // не понятно за что
}

// ✅ ХОРОШО
{
  "key": "beard-shape",
  "name": "Beard Shaping & Trim",
  "description": "Professional beard design with hot towel and aftershave. Includes neck cleanup.",
  "duration_min": 25,
  "price": 20
}
```

---

### 4. Команда (барберы)

#### Каждый барбер должен иметь
- ✅ **Уникальный ID** (`key`) - ivan, petr, ahmed
- ✅ **Имя** (`name`) - полное имя
- ✅ **Должность** (`title`) - например: "Head Barber", "Master"
- ✅ **Биография** (`bio`) - 1-2 предложения
- ✅ **Фото** (`photo`) - профессиональный портрет
- ✅ **Специализация** (`specialties`) - 2-4 пункта
- ✅ **Кодовое имя** (`marker`) - 2 буквы (AH, KA, IV)
- ✅ **Услуги** (`services`) - список ID услуг которые оказывает
- ✅ **Расписание** (`schedule`) - по дням недели
- ✅ **Перерывы** (`breaks`) - обеденные перерывы

#### Хорошее описание:
```json
{
  "key": "ahmed",
  "name": "Ahmed",
  "title": "Barbershop Master",
  "bio": "15+ years in professional barbering. Specialist in fades, beard work and traditional cuts.",
  "specialties": ["Fade Cuts", "Beard Work", "Classic Cuts"],
  "marker": "AH",
  "services": ["haircut", "beard-trim", "skin-fade"]
}
```

---

### 5. Часы работы и расписание

#### Требования
- ✅ Указаны для каждого дня недели
- ✅ 24-часовой формат (09:00, не 9:00 AM)
- ✅ Реалистичны (не 00:00-23:59)
- ✅ Перерывы указаны (обеденный, переходы между клиентами)

#### Пример:
```json
"opening_hours": {
  "mon": ["09:00-19:00"],
  "tue": ["09:00-19:00"],
  "wed": ["09:00-19:00"],
  "thu": ["09:00-19:00"],
  "fri": ["09:00-20:00"],
  "sat": ["09:00-18:00"],
  "sun": []  // выходной
}
```

#### Несколько смен (если есть):
```json
"mon": ["09:00-14:00", "15:00-19:00"]  // с перерывом 14:00-15:00
```

### 6. Правила и политика

#### Обязательные поля
- ✅ **Минимальное время бронирования** (`min_lead_min`)
  - Как минимум за сколько минут можно забронировать
  - Пример: 60 минут, 30 минут, 2 часа

- ✅ **Максимум дней вперёд** (`max_advance_days`)
  - На сколько дней можно бронировать заранее
  - Пример: 30 дней, 60 дней, 90 дней

- ✅ **Отмена** (`cancellation`)
  - Разрешена ли отмена
  - За сколько часов нужно предупредить

- ✅ **Перенос** (`reschedule`)
  - Разрешен ли перенос
  - За сколько часов нужно предупредить
  - Сколько переносов разрешено

#### Пример:
```json
"rules": {
  "slot_step_min": 30,              // слоты по 30 минут
  "min_lead_min": 60,               // минимум за час
  "max_advance_days": 60,           // на 2 месяца вперёд
  "cancellation": {
    "allowed": true,
    "min_notice_hours": 24          // отмена за 24 часа
  },
  "reschedule": {
    "allowed": true,
    "min_notice_hours": 24,
    "max_per_booking": 3            // максимум 3 переноса
  }
}
```

### 7. Легальная информация

#### Impressum (обязательно для ЕС!)
- ✅ **Юридическое название** компании
- ✅ **Представитель** (владелец/директор)
- ✅ **Адрес**
- ✅ **Email**
- ✅ **Телефон**
- ✅ **Страна**

#### Privacy (политика конфиденциальности)
- ✅ **Хостинг** - где данные хранятся (Supabase, Cloudflare)
- ✅ **Хранение** - как долго хранятся данные клиентов (обычно 24 месяца)

#### Пример:
```json
"legal": {
  "impressum": {
    "legal_name": "KAYAN CUT GmbH",
    "represented_by": "Ahmed K.",
    "street": "Beispielstraße 123",
    "postal_code": "10115",
    "city": "Berlin",
    "country": "Deutschland",
    "email": "info@kayan-cut.de",
    "phone": "+49 30 12345678",
    "dispute_resolution": "not_willing"
  },
  "privacy": {
    "retention_months": 24,
    "hosting": "Supabase (EU, Frankfurt) · Cloudflare Pages",
    "extra_processors": []
  }
}
```

## 🎨 Рекомендации по дизайну

### Цвет (брендинг)
- Выбери основной цвет салона (accent_color)
- Второстепенный - фон (обычно тёмный)
- Избегай слишком яркого, режущего в глаза
- Проверь контрастность (для доступности)

### Фото
- **Профессиональное качество** - не смартфон из рук
- **Хорошее освещение** - естественный свет лучше
- **Актуальное** - не старые фото из 2015 года
- **Репрезентативное** - покажи лучшее!

### Текст
- **Четко и по делу** - не "ооо супер клиники"
- **На локальном языке** - если Berlin → по-немецки
- **Профессиональный тон** - уважай клиента

## 💡 Pro Tips

1. **Тестирование**: Сначала добавь тестовый салон, проверь всё работает
2. **SEO**: Хорошее описание в `description` - поможет в поиске

5. **Мобильность**: Проверь как выглядит на телефоне!
