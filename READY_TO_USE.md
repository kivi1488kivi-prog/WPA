### 🔧 Как работает система

1. **Корень** (`/`) → пусто (EmptyState)
2. **По слагу** (`/s/{slug}/`) → загружается салон из `tenants/{slug}/business.json`
3. **Каждый салон** имеет свой брендинг, услуги, команду
4. **Сборка** (`npm run build`) генерирует HTML shells для каждого салона
5. **Деплой** (`npx wrangler pages deploy`) заливает на Cloudflare

## 📞 Поддержка

### Если что-то не работает

1. **Ошибка при сборке** → проверь JSON синтаксис в `business.json`
   ```bash
   cat tenants/my-shop/business.json | jq .
   ```

2. **Приложение не загружается** → открой DevTools (F12) → Console → смотри ошибки

3. **Фото не загружаются** → проверь что файлы в правильной папке `/images/`

4. **Расписание некорректно** → проверь часовой пояс в `business.json`

5. **Домен не работает** → [DOMAIN_SETUP.md](./DOMAIN_SETUP.md) → раздел "Если что-то не работает"
